Judul Proyek
PM-TRAVEL: Sistem Pemantauan Lokasi dan Estimasi Waktu Tiba Kendaraan Travel Berbasis IoT

Identitas Proyek
PM-TRAVEL merupakan proyek pengembangan prototipe sistem pemantauan kendaraan travel untuk mendukung kebutuhan agen atau operator travel di Bandar Lampung. Sistem dirancang untuk mengirimkan data lokasi kendaraan secara berkala dan menampilkan estimasi waktu tiba atau Estimated Time of Arrival (ETA) melalui dashboard web.
